# SillyTavern-ChatRecap
![Screenshot of ChatRecap](/img/BloodyValentine.png)

Have you ever come back to a chat after a week and find out you can't remember what happened? Or maybe only after a few days. Well this fixes that issue, as few seconds after you open a chat a popup would give you a recap on your chat history so it can refresh your memory.

> [!Important]
> This extension has been created with Kimi and is vibecoded. If you don't trust it, you don't like it or you don't support it is absolutely fine, this was to scratch my own itch more than anything and I use it myself. Always audit any code before using it.

## How to install

Copy the github URL into the extension tab > Install extension

```
https://github.com/ravenrevenge/SillyTavern-ChatRecap/
```

## How to use
![Settings screenshot](/img/Settings.png)

- **Connection Profile**: Choose any connection you want to use for the recap, use a cheaper model, a local model, a simpler prompt... whatever you want. I recommend non thinking models with thinking `auto`
- **Time Threshold**: The amount of hours that have to pass before a recap is triggered when you open the chat
- **Show Time Away Label**: Enable or Disable the text "last seen X time ago" inside the pop-up.
- **Prompt Template**: Whatever instructions you want to send the AI for the summary to be generated. It comes with a generic short one by default, but I encourage you to make your own and have fun.
- **Test Recap Now**: Open a chat and press the button to trigger it on demand.

I recommend making your own prompt, maybe add some fun to it asking it to resume it like a telenovela, or a tv host, maybe ask it to use internet slang, make it comical, or like a medieval announcement... 

The pop-up uses SillyTavern native variables, buttons and elements and it will automatically blend with any theme you have. It's compatible with Moonlit Echoes and mobile phones and tablets. 

It's ready to be translated too and it comes with Spanish translation already. I'm happy to accept PRs with more translations <3 It translates both the settings and anything in the pop-up except the recap, that would depend on the language of your prompt and chat history.
